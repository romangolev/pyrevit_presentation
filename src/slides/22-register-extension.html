Registering Your Extension

Option 1 — PyRevit Settings UI

  1. PyRevit tab → Settings
  2. Custom Extension Directories
  3. Add path to your extension's parent folder
  4. Reload PyRevit

Option 2 — CLI

pyrevit extend ui MyTools \
  /path/to/MyTools.extension

pyrevit reload
Point PyRevit at the parent directory of MyTools.extension, not at the extension folder itself.
The parent-folder convention allows you to put multiple extensions in one repo / directory.
