First Launch

  • PyRevit ribbon tab is added to Revit
  • Default extensions pre-loaded (~60 tools)
  • PyRevit Settings panel — configure python engine, output window
  • PyRevit Console (REPL) — run Python against the live model
  • Extension Manager — browse & install community tools
Hot-reload: Edit any script.py, click the button again — changes take effect immediately. No Revit restart.
The REPL is a game-changer for learning the Revit API. You can try API calls without writing a full script.
