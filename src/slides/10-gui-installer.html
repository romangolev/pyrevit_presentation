Option A — GUI Installer

  1. Go to pyrevitlabs.io → Downloads
  2. Download pyRevit_X.X.X_installer.exe
  3. Run installer — picks up installed Revit versions automatically
  4. Launch Revit → PyRevit ribbon tab appears
Recommended for individual users. Installer handles attaching PyRevit to each detected Revit version.
The installer creates a clone in %APPDATA%\pyRevit-Master and writes the .addin manifest for each Revit version found.
