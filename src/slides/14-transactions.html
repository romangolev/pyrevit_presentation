Transactions

Standard transaction

from pyrevit import revit, DB

with revit.Transaction("Set Parameter"):
    elem.LookupParameter("Comments") \
        .Set("Reviewed")

Auto-commits on success; rolls back on any exception.

Dry / preview run

from pyrevit import revit

with revit.DryTransaction("Preview"):
    # Modify elements, read results,
    # transaction is always rolled back
    new_area = calc_area(elem)

print("Would be:", new_area)

Useful for what-if calculations without touching the model.

DryTransaction is a PyRevit addition — not in the raw Revit API. Very handy for read-only analysis that needs to temporarily modify elements.
