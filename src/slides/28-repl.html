PyRevit Console — REPL

Interactive Python shell with the live Revit document in scope:

# Open via: PyRevit tab → PyRevit Console
# All pyrevit imports already available

# Count all doors in the current model
from pyrevit import DB, revit
doors = DB.FilteredElementCollector(revit.doc) \
          .OfCategory(DB.BuiltInCategory.OST_Doors) \
          .WhereElementIsNotElementType() \
          .GetElementCount()
print(f"Doors: {doors}")
# → Doors: 347
