Interactive Output & Hot-Reload

Edit script.py, click the button — instant results in the output window:

# Any pushbutton script — edit and re-run instantly
from pyrevit import DB, revit, script

output = script.get_output()

# Count all doors in the current model
doors = DB.FilteredElementCollector(revit.doc) \
          .OfCategory(DB.BuiltInCategory.OST_Doors) \
          .WhereElementIsNotElementType() \
          .GetElementCount()

output.print_md("**Doors in model:** {}".format(doors))
# → Doors in model: 347
Fast feedback loop. Edit your script, click the button again — no restart, no compile. The output window supports HTML, Markdown, charts, and clickable element links.
Hot-reload is the fastest way to learn the Revit API — no compile, no deploy, immediate output. The output window can also render tables, charts, and clickable links that select elements in the model.
