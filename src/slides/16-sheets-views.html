Sheets & Views Tools

  • Sheet Index — generate a schedules-style sheet list
  • Rename Views — bulk rename with find & replace
  • Match Viewports — align viewport positions across sheets
  • Flip Views — mirror view crops in bulk
  • Create Sheet Set — batch-create sheets from a list
Most tools open a PyRevit forms dialog — no WPF XAML required.
These are among the most used tools on real projects. Sheet Index alone saves hours of manual bookkeeping.
