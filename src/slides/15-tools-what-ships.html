pyRevitTools.extension

The default extension ships ~60 tools organised into panels:

Sheets & Views

Sheet Index, Rename Views, Match Viewports, Flip Views

Model Review

Warnings Report, Model Checker, Purge Unused, Element Counter

BIM Utilities

Family Browser, Parameter Manager, Links Manager, Workset Inspector

All tools are open source — great learning resource. Read any script at %APPDATA%\pyRevit-Master\extensions\pyRevitTools.extension
The tools folder is also a living example of PyRevit patterns — forms, transactions, hooks, all represented.
