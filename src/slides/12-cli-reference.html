CLI Command Reference

CommandDescription
pyrevit clonesList registered PyRevit clones
pyrevit attach <clone> <revit-year>Attach a clone to a Revit version
pyrevit detach <revit-year>Remove PyRevit from a Revit version
pyrevit extensionsList installed extensions
pyrevit extend lib <git-url>Install a community extension from Git
pyrevit logsOpen PyRevit log files
pyrevit updateUpdate all clones to latest
The CLI is the power-user interface. For a team rollout you'd script the clone + attach steps in a PowerShell deployment script.
