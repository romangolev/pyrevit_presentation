Installation

Option A — GUI Installer

  1. Go to pyrevitlabs.io → Downloads
  2. Run pyRevit_X.X.X_installer.exe
  3. Launch Revit → PyRevit tab appears

Recommended for individual users.

Option B — CLI (Chocolatey)

choco install pyrevit-cli
pyrevit clone default
pyrevit attach default 2024
pyrevit clones

Ideal for CI/CD & team deployments.

GUI installer creates a clone in %APPDATA%\pyRevit-Master. CLI gives full control — multiple clones, different Revit versions. Also available as signed EXE/MSI from GitHub Releases.
