Model Review & Cleanup

  • Warnings Report — export all Revit warnings to Excel / CSV
  • Model Checker — configurable rule-based QA
  • Purge Unused — safe incremental purge with preview
  • Element Counter — count elements by category
  • Room / Area Checker — find unenclosed rooms
Note: Always run Purge Unused on a copy first — it is non-reversible after save.
The Warnings Report is widely used on large projects to track progress on model health.
