Option B — CLI Install

# 1. Install PyRevit CLI via Chocolatey (recommended)
choco install pyrevit-cli

# 2. Clone the default PyRevit release
pyrevit clone default

# 3. Attach to Revit 2024
pyrevit attach default 2024

# 4. Verify
pyrevit clones

CLI gives full control — ideal for CI/CD, shared workstations, automated deployments.
Also available as a signed EXE or MSI installer from GitHub Releases.

"Clone" in PyRevit terminology means a local copy of the PyRevit source / release. You can have multiple clones (e.g. stable + dev) and attach different ones to different Revit versions.
