Requirements

  • Autodesk Revit 2018 or newer
  • Windows 10 / 11 (64-bit)
  • Python — bundled with PyRevit, no separate install
  • .NET Framework 4.8 (ships with Windows)
  • ~500 MB disk space
No admin rights needed for per-user install.
Works alongside other add-ins.
Mac / Linux: not supported —
Revit is Windows-only.
The bundled Python is IronPython 2.7. CPython 3.x support is opt-in per script using the #! pragma.
