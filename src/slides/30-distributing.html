Distributing via Git

Author publishes:

  • Push extension folder to a Git repo
  • Tag releases with semantic versioning
  • Optionally publish to PyRevit extension index

Team installs:

pyrevit extend lib MyTools \
  https://github.com/org/mytools.git

# Update to latest
pyrevit update MyTools
Combine with a PowerShell onboarding script → new Revit workstation configured in under 2 minutes.
Git is the distribution layer. No installer, no zip file, just a URL. For internal tools, a private Git repo works fine.
