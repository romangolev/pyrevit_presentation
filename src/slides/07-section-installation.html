Installation & Setup

Two paths: GUI installer or CLI.

Executable

  • pyRevit_6.1.0_signed.exe — installer
  • pyRevit_6.1.0_admin_signed.exe — admin installer
  • pyRevit_CLI_6.1.0_signed.exe — CLI executable
  • pyRevit_CLI_6.1.0_admin.msi — CLI MSI

Latest release: v6.1.0

CLI

# Install via Chocolatey
choco install pyrevit-cli

# Clone & attach to Revit
pyrevit clone default
pyrevit attach default 2024

# Verify
pyrevit clones

Ideal for CI/CD & team deployments.

Left column has direct download links to the latest signed release artifacts from GitHub. Right column shows the Chocolatey CLI workflow for automated/team setups.
