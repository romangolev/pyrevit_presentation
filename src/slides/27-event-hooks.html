Event Hooks

React to Revit events — no EventHandler boilerplate:

# hooks/doc-opened.py   ← file name = event name

from pyrevit import script, forms, DB
import hooks  # pyrevit hooks module

logger = script.get_logger()

# __eventargs__ is injected by PyRevit
doc = __eventargs__.Document

# Check for warnings on every open
warnings = doc.GetWarnings()
crit = [w for w in warnings if "overlapping" in w.GetDescriptionText().lower()]

if crit:
    logger.warning("{} critical warnings found".format(len(crit)))
    forms.alert(
        "{} overlapping element warnings detected.\nReview before proceeding.".format(len(crit)),
        title="Model Health Check",
        warn_icon=True
    )

Available hooks: doc-opened, doc-saved, doc-synced, doc-closing, view-activated, and more.

Place the file in a hooks/ folder inside your extension. The file name must match the event slug exactly. __eventargs__ is a magic variable injected at runtime by the PyRevit engine.
